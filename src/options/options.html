Context Lens

Select text on any page, then click Explain (or press ⌘⇧E / Ctrl⇧E).

Haiku 4.5 answers a popup-sized question in about a second. The slower options think before answering and are worth it only for dense material.

The key is stored in this browser's extension storage and sent directly to api.anthropic.com from the extension. Anyone with access to this browser profile can read it.
